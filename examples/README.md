# Simulated fixture data

These six events were generated by an early integration test. Every record is explicitly simulated, from a fictional world and server. They are examples, not evidence from a Minecraft server.

`events.json` demonstrates the early event model and `events.csv` is an export of the same snapshot. To create a fresh sample in-game, run `/coreviewer simulate` with Coreviewer enabled. Do not select simulated data when reviewing real investigations.
