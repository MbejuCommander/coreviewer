# Simulated fixture data

These six events were generated by the Phase 1 integration test. Every record is explicitly simulated, from a fictional world and server. They are examples, not evidence from a Minecraft server.

`events.json` demonstrates all three typed event models and six action types. `events.csv` is the export of the same snapshot. To create your own fresh sample in-game, run `/coretrace simulate` with CoreTrace enabled.
